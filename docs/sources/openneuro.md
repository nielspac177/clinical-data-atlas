# OpenNeuro

- **Source id:** `openneuro` · **Harvester:** `atlas/harvest/openneuro.py` · **Normalizer:** `atlas/normalize/openneuro.py`
- **Endpoint(s):** POST `https://openneuro.org/crn/graphql` -- `datasets(first, after, orderBy: {created: descending}) { pageInfo { hasNextPage endCursor count } edges { node { id created publishDate metadata { ... } latestSnapshot { tag description { ... } readme summary { ... } } } } }`, paged 100/request · **Auth:** none · **Politeness:** 350 ms/host (`atlas.http` default), UA `clinical-data-atlas/<ver> (+repo; mailto:...)` · **robots.txt:** verified live 2026-08-22 -- `User-agent: * / Allow: /` (fully permissive; the site is a SPA anyway, so GraphQL is the only real route to the data)
- **Verified:** 2026-08-22 · **Count:** 1,864 datasets (`pageInfo.count`, live) · **Deviation from brief:** none in the endpoint/query itself (the brief's query shape matches live exactly). The brief's per-field mapping leaves a few rules underspecified for real data; this normalizer fills them in explicitly -- see Quirks 6, 7, 8, 10 below -- rather than guessing silently.

## Quirks

1. **A small fraction of dataset nodes fail to resolve server-side.** Across a live sample of ~1,000 datasets (10 pages), 6 edges (~0.6%, up to 4 in a single page of 100) came back as GraphQL partial-failures: the response's top-level `errors[]` reports `"Not Found"` resolving `node.metadata` or `node.latestSnapshot` for that dataset, and the *entire* `edges[i]` element is JSON `null` as a result -- not just the failed field, and with no `id` recoverable at all. The rest of that page's `data` (including `pageInfo`) is unaffected. The harvester skips `null` edges (and, defensively, edges whose `node` is `null`) rather than failing the whole page; `tests/fixtures/openneuro/listing.json` is a real captured 5-edge window containing two such `null` edges, used to test this directly.
2. **`readme` can be JSON `null`**, not just `""`, even when `latestSnapshot` itself is present (observed on a real dataset, `ds006676`). Handled via `snapshot.get("readme") or ""` throughout.
3. **Unfinished BIDS submissions leave a stock `Authors` placeholder** -- observed verbatim, identically, in 12 of ~994 sampled datasets: `["TODO:", "First1 Last1", "First2 Last2", "..."]`. All four entries are filtered out (matches the brief's "drop placeholders TODO/First1 Last1"); the trailing `"..."` is also dropped since it only ever appears as part of this same stock template and is not a name.
4. **Unfinished submissions also leave a stock `readme` placeholder** -- observed verbatim: `"TODO: Provide description for the dataset -- basic details about the study, possibly pointing to pre-registration (if public or embargoed)"`. Detected as a placeholder (stripped text starts with "todo", case-insensitive) and never used for `summary`; the templated one-liner is used instead.
5. **`associatedPaperDOI` / `ReferencesAndLinks` are hand-typed free text**, not structured DOI fields: multiple DOIs comma-separated, `doi:`/`https://doi.org/`/`https://dx.doi.org/` prefixes (all three observed), trailing sentence punctuation glued directly to a DOI, non-DOI links (OSF, arXiv abstract pages, NeurIPS posters, GitHub, HuggingFace), garbage values (`"TDB"`), and -- concretely, in `ds008159` -- **the dataset's own DOI**, an older `.v1.0.0` of itself, cited in `ReferencesAndLinks` as a "please also cite this dataset" note. Handled by scanning both fields with a DOI-shaped regex, stripping trailing punctuation (`.,;:)]}'"`) that the regex's greedy match otherwise swallows, version-collapsing and deduplicating every match, and excluding any match equal to the record's own (version-collapsed) `dataset_doi`.
6. **License strings are short-form and don't match `vocab.LICENSE_MAP`'s long-form entries.** OpenNeuro reports `"CC0"` (976/994 sampled -- maps cleanly), but also `"CC-BY-SA 4.0"` and `"CC-By Attribution 4.0 International"`, neither of which equals (exactly or case/whitespace-normalized) `vocab.LICENSE_MAP`'s long-form `"Creative Commons Attribution-ShareAlike ..."`/`"Creative Commons Attribution 4.0 International Public License"` keys. Per `docs/schema.md`'s documented semantics ("SPDX when mappable via `vocab.LICENSE_MAP`, else the source's verbatim string"), this normalizer keeps the verbatim string in that case rather than nulling it out. This reads the brief's shorter "`license=LICENSE_MAP[License]` (null if absent -- never assume)" as "null only when `License` itself is absent/empty" -- not "null whenever it fails to map" -- since the latter would silently discard a real, present license string the schema explicitly says to preserve verbatim.
7. **`metadata.species` is messy free text**, not a controlled vocabulary: `""`, `null`, `"Human"`, `"Rat"`, `"Mouse"`, `"Macaque"`, `"rhesus monkey"`, `"Other"` all observed. Mapped as: `"human"` (case-insensitive) -> `human`; any other non-empty value -> `animal` (this field is only ever used for a living study subject on OpenNeuro, never phantom/simulated data, so "present and not human" reliably means "animal" -- including the bare `"Other"` value); empty/null -> `human` if `affirmedDefaced` else `unknown` (per the brief; defacing is meaningless for non-human/no-subject data, so affirming it is itself weak evidence of a human subject).
8. **`studyDomain`/`dxStatus` are unrestricted free text.** Domain classification here is a deliberately small, explicit, case-insensitive substring rule (`"neurolog"` -> `neurology`, `"psychiat"` -> `psychiatry`; both can apply if both substrings are present; else `neuroscience`) -- exactly what the brief calls for at normalize time, and not a substitute for the richer keyword classification the later enrich stage does from `enrichment_text`.
9. **`dxStatus`-to-condition matching is a plain case-insensitive substring scan** against `vocab.CONDITION_ALIASES` keys, with no punctuation/whitespace normalization beyond casing. `"Healthy / Control"` (the common form) matches the alias key `"healthy / control"`; a differently-spaced variant like `"Healthy/Control"` (seen in at least one sampled dataset, not one of the five fixtures) would not. Acceptable given `vocab.py`'s own framing of `CONDITION_ALIASES` as a seed set that later enrichment extends.
10. **`population` uses the source's raw species/dxStatus text, not the coerced `species` enum.** A dataset with `metadata.species: null` still gets the schema-required `species: "human"` (via `affirmedDefaced`, quirk 7) but an omitted species clause in the free-text `population` field -- `population` only ever states what the source's free text literally said, never the enum's own empty-value fallback.

## Field mapping

| raw | canonical | transform |
|---|---|---|
| `node.id` | `id`, `source_native_id` | `id = "openneuro:<node.id>"` |
| `node.id` | `url` | `"https://openneuro.org/datasets/<node.id>"` |
| `latestSnapshot.description.Name` | `name` | stripped; falls back to `node.id` if blank |
| `latestSnapshot.readme` | `summary` | first 40 words (`io.first_words`) if non-empty and not the stock "TODO" placeholder (quirk 4); else `"<name>: <modalities joined>  dataset on OpenNeuro (<sample_size> participants)."` |
| `latestSnapshot.summary.modalities` | `modalities` | `{mri:MRI, eeg:EEG, meg:MEG, ieeg:iEEG, pet:PET, nirs:fNIRS, mrs:MRS, beh:behavioral, motion:wearable, micr:pathology, ct:CT}`, case-insensitive; unmapped values -> `keywords` |
| `latestSnapshot.summary.secondaryModalities` | `modalities` | `{mri_functional:fMRI, mri_diffusion:dMRI, mri_structural:MRI, mri_perfusion:MRI}`; unmapped -> `keywords`; union with the above, vocab-ordered |
| `metadata.species`, `metadata.affirmedDefaced` | `species` | quirk 7 |
| `metadata.species`, `metadata.dxStatus`, `metadata.ages` | `population` | `"<species>; <dxStatus>; ages a–b"`, each part included only if present (quirk 10) |
| `metadata.dxStatus` | `conditions` | case-insensitive substring match against `vocab.CONDITION_ALIASES` (quirk 9) |
| `metadata.studyDomain`, `metadata.dxStatus` | `domains` | quirk 8 |
| `latestSnapshot.summary.subjects` | `sample_size` | `len(subjects)`; `sample_unit = "participants"` |
| `latestSnapshot.summary.size` | `size_bytes` | verbatim |
| `latestSnapshot.description.License` | `license` | `vocab.LICENSE_MAP` lookup (exact or normalized) -> SPDX id; else the verbatim string if present; `null` only if `License` is absent (quirk 6) |
| `latestSnapshot.description.DatasetDOI` | `dataset_doi` | `common.clean_doi` + `common.collapse_version_doi` |
| `latestSnapshot.tag` | `version` | verbatim |
| `node.publishDate` | `published` | first 10 characters (`YYYY-MM-DD`) |
| `latestSnapshot.description.Authors` | `authors` | stock placeholder entries dropped (quirk 3) |
| `metadata.associatedPaperDOI`, `latestSnapshot.description.ReferencesAndLinks` | `papers` | DOI-shaped regex scan of both fields, deduplicated, self-DOI excluded (quirk 5); `relation = "describes"` |
| *(constant)* | `access`, `access_tiers` | `"open"`, `["open"]` -- every dataset reachable through this public, unauthenticated listing |
| `latestSnapshot.summary.tasks` | `keywords` | verbatim, plus any unmapped modality strings (see `modalities` rows) |
| *(not reported by the queried fields)* | `years`, `countries`, `institutions`, `related` | left empty/unset -- `created`/`publishDate` are upload dates, not data-collection years, and this query exposes no country or institution field; never fabricated |
