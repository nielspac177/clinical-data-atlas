# Clinical Data Atlas — Implementation Plan (Phase 0 → live product, + Phases 1–3 roadmap)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (fresh subagent per task + spec/code review between tasks). Steps use checkbox (`- [ ]`) syntax for tracking. After approval this file is copied into the repo as `docs/superpowers/plans/2026-08-22-clinical-data-atlas-phase0.md`; the brief + the decisions below become `docs/superpowers/specs/2026-08-22-clinical-data-atlas-design.md`.

**Goal:** Ship a public, living, explorable catalog of open & gated clinical/neuroscience datasets — a 3D knowledge graph + filterable table on GitHub Pages — fed by a one-command, reproducible, monthly-refreshable metadata pipeline, then iterate with adversarial review rounds until it meets objective quality gates.

**Architecture:** `atlas/` Python package (harvest → normalize → enrich → dedupe → graph → diff) writes committed, provenance-carrying data (`data/raw`, `data/catalog/catalog.jsonl`, `data/graph/*.json`, `data/changelog/*.md`). `site/` is a vanilla-JS static site (vendored `3d-force-graph`) assembled into `_site/` by `python -m atlas.sitebuild` and deployed by GitHub Actions to Pages. A monthly Actions cron runs the refresh and opens a PR with the human-readable diff; merging deploys. An adversarial multi-agent quality loop (Workflow rounds + self-paced `/loop`) drives the product to its definition of done.

**Tech Stack:** Python 3.12 (`.python-version`), uv, pydantic v2, stdlib `urllib` HTTP layer (ported from `~/neurodatahub/scripts/lib/http.py`), pytest (+ pytest-playwright for e2e), `markdown` (changelog → HTML), optional `anthropic` extra; site: vanilla ES modules + `3d-force-graph@1.80.0` UMD (vendored), system fonts, no bundler; GitHub Pages via `actions/deploy-pages`, `peter-evans/create-pull-request@v8`, `astral-sh/setup-uv` pinned by SHA.

**Spec:** PROJECT_BRIEF.md (user-supplied, verbatim) + "Decisions & assumptions" + "Frozen schema v1" + "Data contracts" sections below.

## Global Constraints (from the brief — apply to every task)
- Metadata only, never data: never download/rehost dataset contents; restricted sources from public docs only.
- APIs first, polite scraping second, never against ToS: descriptive `User-Agent` (`clinical-data-atlas/<ver> (+https://github.com/nielspac177/clinical-data-atlas; mailto:<MAILTO>)`), per-host ≥350 ms politeness, retries w/ backoff, robots.txt respected/flagged.
- One canonical schema; provenance on every record (`provenance.harvested_via/harvested_at/last_verified`).
- Reproducible refresh: `make refresh` == `python -m atlas.refresh` runs end-to-end and writes a diff; one broken source must not kill the run (reported instead).
- Verify every API live before writing its harvester; deviations recorded in `docs/sources.md`.
- Python ≥3.11, minimal deps, typed where it helps; cache raw responses in `data/raw/`; small conventional commits (`harvest: add TCIA collections`); never fabricate a record; tests = schema validation on every record + smoke test per harvester on cached fixture (+ live probe behind `ATLAS_LIVE=1`).
- No network in unit tests (`ATLAS_OFFLINE=1` socket guard in `tests/conftest.py`).
- Generated outputs are deterministic (sorted keys, vocab-ordered lists, no timestamps in graph/search/raw record files).

## Frozen schema v1 (pydantic model `atlas/schema.py`; JSONL one record per line, keys sorted)
Required unless marked O. Lists default `[]`.
- `id` `<source>:<source_native_id slug>` (regex `^[a-z_]+:[A-Za-z0-9._-]+$`); `source` enum `openneuro|physionet|gdc|tcia|scientific_data|data_in_brief|dhs|worldbank|curated`; `source_native_id`; `name`; `summary` (≤40 words, enforced); `url` (http/https)
- O `dataset_doi` (version-collapsed), O `version`, O `published` (ISO date)
- `domains[]` enum (17): `neurology, psychiatry, neuroscience, cardiology, oncology, pulmonology, critical_care, surgery, pediatrics, obstetrics_gynecology, infectious_disease, endocrinology_metabolism, gastroenterology_hepatology, nephrology_urology, musculoskeletal, public_health, other`
- `modalities[]` enum (33): `MRI, fMRI, dMRI, MRS, PET, SPECT, CT, xray, mammography, ultrasound, radiotherapy, pathology, EEG, MEG, iEEG, fNIRS, ECG, EMG, PPG, physiological_signals, wearable, eye_tracking, behavioral, genomics, transcriptomics, proteomics, EHR, clinical_notes, claims, registry, survey, clinical_tabular, other`
- `conditions[] {label, mesh_id?}`; O `keywords[]`; O `population`; `species` enum `human|animal|mixed|phantom|simulated|unknown`
- `sample_size` int|null + `sample_unit` enum `participants|cases|admissions|records|images|studies|series|households|surveys|other`|null; O `size_bytes`
- `countries[]` ISO-3166-1 alpha-2; `years {start,end}` ints|null
- `access` enum `open|registration|credentialed|application|purchase` (ordered; conflicts → more restrictive); O `access_tiers[]`; O `access_notes`; O `access_howto`
- O `license` (SPDX when mappable via `LICENSE_MAP`, else verbatim)
- `institutions[] {name, ror_id?, country?}`; `authors[] {name, orcid?}`; `papers[] {doi, title?, relation: describes|cites|is_cited_by|other}`; `related[] {id, relation: same_cohort|duplicate_of|derived_from|part_of}` (ids must exist)
- `record_status` `active|needs_review|removed`
- `provenance {harvested_via, harvested_at, last_verified, raw_hash?, enrichment {method: rules|llm|rules+llm|curated, model?, prompt_version?, at?, fields: {field: origin}}}`
Validation: errors = model failure, duplicate id, dangling related, summary > 40 words, bad url; warnings = empty domains/modalities, non-open access without access_notes, sample_size without unit. `atlas schema --export` writes `docs/schema.json` + `docs/schema.md`; CI fails on drift.

## Data contracts (consumed by the site — fixed)
- `data/graph/graph.json`: `{"nodes":[{id,type:dataset|modality|condition|institution|source,label,source?,domains?,access?,degree,backbone?:true}],"links":[{source,target,type}]}`; ids `modality:EEG`, `condition:<slug>`, `institution:<ror|slug>`, `source:<source>`; edges dataset→source/modality/condition/institution(top 3), dataset↔dataset (related). Backbone = all non-dataset nodes except institutions with degree<2; top-30 conditions flagged; ≈1.1 MB.
- `data/graph/search-index.json`: rows `{id,name,summary,source,domains,modalities,conditions(labels),countries,access,years,sample_size,sample_unit,url,species}` sorted by id.
- `data/graph/stats.json`: `{record_count, per_source, per_domain, per_modality, per_access, backbone_count}` (no dates).
- `data/catalog/catalog.jsonl` (+ `excluded.jsonl` with `{id, reason}`); site build splits into `_site/data/records/<source>/<native>.json`.
- `data/changelog/YYYY-MM-DD.md` + `latest.md`; site build renders newest 12 into `whats-new.html`.

## M5 — Adversarial quality loop (Workflow tool + `/loop`)
State files: `docs/quality/rounds/NN.md`, `docs/quality/findings.jsonl` (`{id, round, lens, severity, file, line, claim, evidence, repro, fix, status: open|fixed|refuted|note, age}`), `docs/quality/scorecard.json` (history), `docs/quality/README.md`, final `docs/quality/REPORT.md`; one GitHub tracking issue per phase with a comment per round.
ROUND(n):
1. `parallel()` reviewers with fixed lenses → findings JSON (schema above): **data-correctness** (20 seeded records + previously-fixed ids: open `url` + source API, compare name/access/license/sample_size/modalities; fabrication hunt), **pipeline-code** (bugs, silent excepts, nondeterminism, idempotency `refresh` twice → empty diff, isolation, retries/timeouts), **site-ux-a11y** (Playwright screenshots desktop+mobile × themes, keyboard path, contrast, console errors, broken links, horizontal scroll, base path), **performance** (payload budgets, time-to-backbone, frame time), **security-hygiene** (secrets, robots/ToS per source, rate limiting + UA, no data redistribution, pinned deps), **docs** (sources.md endpoints+dates, schema drift, README quickstart from scratch).
2. Verification: each finding → 2 skeptics (`refute`, `reproduce`) who run the repro; CONFIRMED if ≥1 reproduces and none refutes; split → third judge (majority); both unverifiable → note.
3. Fix: group confirmed by area with disjoint globs (`atlas/harvest|normalize`, `atlas/enrich|graph|refresh`, `site/`, `docs/`, `.github/`, `tests/`); one fixer per area in `git worktree add .worktrees/fix-r{n}-{area}`; failing test/assert before fix, passing after; `make test`; commit `fix(<area>): … [R{n}-ID]`; orchestrator merges sequentially (`--no-ff`), reruns fixer on conflict. Data findings fixed in code + re-materialized with `make refresh SOURCE=x` (never hand-edit catalog).
4. Re-verify: `make test site e2e` + rerun every confirmed repro; unfixed carry over `age+1` (age ≥2 → escalate in report).
5. Score: lens = max(0, 100 − Σ open penalties [critical 40, high 15, medium 5, low 1]); overall weights data 25, site 20, pipeline 15, performance 10, security 10, docs 10, DoD 10; caps: open critical ≤59, open high ≤84.
6. Exit: two consecutive rounds with 0 open high/critical AND score ≥90 AND `make dod PHASE=n` green → stop; cap 6 rounds/phase → report residuals.
`/loop` cadence (self-paced via ScheduleWakeup): each wake-up reads scorecard + last round, checks `gh run list --limit 5`; (a) red CI/deploy → fix; (b) open findings → run next ROUND now; (c) clean round → sleep ~25 min (let deploy land, next round reviews the live Pages URL); (d) exit criteria met → write REPORT.md, update memory, stop loop. After Phase 0 exits, continue with Phase 1 plan (journals), then Phase 2, then Phase 3 polish, each under the same loop — budget permitting.
